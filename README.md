# WAKUKU 苔苔喂养陪伴 · Demo 14

本仓库仅含喂养陪伴。上传版包括 HTML、模型数据、场景与角色素材、Three.js 0.160.0 运行代码及许可，不依赖远程 CDN。

## 运行

下载整个仓库并解压。保持所有文件在同一目录，打开 `index.html`。如浏览器限制本地文件，运行 `python3 -m http.server 8080`，访问 http://localhost:8080 。也可将全部文件上传到静态 HTTPS 主机。GitHub 仓库页面本身不是试玩地址；本次仅上传，未启用 GitHub Pages。

- 点击莓果或拖到嘴边松手喂食。
- 选择梳子，在衣服上拖动。
- 点击地上的球轻抛，或拖动后甩出，等待捡回再玩。
- 右上设置可重来、关闭/开启声音和触觉、进入休息。

## 文件与来源

`index.html` 包含游戏逻辑与图片。`model-part-*.js` 按顺序加载并在 `wakuku_doll_glb.js` 拼接原始 data URL；没有改成 fetch .glb，模型外观不因拆分改变。约 99 万面的展示模型并非已优化 low poly；下载量和内存较大。

`wakuku-runtime.js` 为本地 Three.js 运行包，源文件也保留在仓库；用 `python3 build-runtime.py` 可重建。Three.js 来源官方 npm 包 three@0.160.0，遵循随附 THREE-LICENSE.txt。模型来源用户指定 Tripo 项目 549ce23f-435e-46c1-b134-b0d21ef5442a，角色素材来自用户提供的 WAKUKU 项目，场景为该项目中的生成素材。角色素材商业授权未独立核验。

浏览器需支持 WebGL、Pointer Events 和 Web Audio。存档仅同源 localStorage，不跨设备同步；声音默认关闭。此版本是可操作体验 Demo，不是全部品质标准已验收的商业版本。

## 中文角色配音更新（取代上述系统 TTS）

现已移除 SpeechSynthesis 系统朗读与设备声线选择。采用 ElevenLabs `eleven_v4` 生成的 Yu-Ting — Sweet and Bubbly 中文声线，共 13 句。分别对应欢迎、喂食、梳毛、捡球、灯光、浇水、风铃、摸摸与休息。录音内嵌于 HTML，Web Audio 解码播放，各设备使用相同配音。设置中可点“试听苔苔 · 轻甜中文”；关闭、后台取消和冷却功能保留。浏览器首次播放仍需点击。音频内容为 AI 合成。

## 场景互动扩展
